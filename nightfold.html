An opening animation for your Galaxy Z Fold. It covers the black flash when the phone switches screens.

Stained Glass · Autumn Leaves · Hologram, on a real Fold

Is it safe?

  • It can't go online. Nightfold doesn't have Android's internet permission, so it has no way to send anything anywhere.
  • Nothing leaves your phone. The home-screen pictures it uses for the effect are kept in Nightfold's own app folder, which other apps can't open, and are deleted if you uninstall.
  • No ads, no accounts, no tracking.
  • All the code is public on GitHub (MIT licence), so anyone can read exactly what it does.
  • Prefer Google Play? A Play Store version is on the way, so Google's checks will cover it too.

What you need

  • A Samsung Galaxy Z Fold running Android 14 or newer
  • Shizuku (free, on Google Play). It lets Nightfold watch the hinge and show the effect over both screens.

Setup

  1. Download the APK, install it and open it.
  2. Tap Get Shizuku, then Start Shizuku (the first time, Shizuku walks you through Wireless debugging).
  3. Tap Allow. The effect turns on.

After a reboot, start Shizuku again. Nightfold reconnects by itself.
